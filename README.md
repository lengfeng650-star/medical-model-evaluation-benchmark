# 医学模型评测集样例

本数据集面向医疗大模型评测、训练验证与应用测试，整理了 10 个医学任务子集，每个子集抽取 100 条高质量样例，共 1000 条。开源版本已重新整理为连续编号 1-10，编号、文件名、清单和表内数据集序号保持一致。内容覆盖导诊、个性化康复指导、个性化用药指导、心理健康咨询、辅助诊断、临床诊疗方案、病情分析、鉴别诊断、诊疗处置建议和病历文本结构化等任务。

样例数据保留了原始任务形态，包括病例描述、问题、答案要求、来源说明和分类字段，适合用于医学问答、临床推理、指令微调样例构建、数据格式参考和模型能力测试。完整数据服务、专项定制或商业合作可发送邮件至 zhouhaoran@shujuyoupu.com。

## 子集说明

### 1 导诊

该子集为医患对话导诊任务。模型需要从患者症状、病史和就医诉求中识别潜在诊断方向，并在给定候选科室范围内推荐合适科室。样例覆盖综合医院及妇产、儿童、肿瘤、中医、精神等专科场景，适合评估模型对症状归纳、科室映射和多科室推荐的能力。

### 2 个性化康复指导

该子集聚焦康复医学问答，覆盖骨科康复、神经康复、疼痛康复、儿童康复、产后康复、心肺康复、老年康复和重症康复。样例包含知识型问答与简要病历型案例，可用于训练模型输出康复目标、方案设计、并发症预防和康复注意事项。

### 3 个性化用药指导

该子集以案例型问答为主，围绕常见疾病和药物治疗方案展开。病例通常包含患者基础信息、病史、检查结果和初始用药方案，要求模型分析用药合理性、疗效不佳或不良反应原因，并给出个性化用药调整建议。

### 4 心理健康咨询

该子集覆盖情绪调节、人际关系、学业或职业焦虑、青少年及孕产妇等特殊人群咨询、心理危机风险干预和慢性心理问题。样例适合用于心理健康问答、风险识别、支持性回应和分级干预建议能力评估。

### 5 辅助诊断-进阶

该子集为进阶辅助诊断多选任务。题干来自复杂病历信息，包含人口统计信息、症状表现、临床关注点、既往治疗、药物史、家族史和系统回顾等内容，要求模型进行系统分析并从选项中选择合适诊断或判断结论。

### 6 临床诊疗方案

该子集提供年龄、性别、疾病史、症状、实验室检查等病历信息，覆盖常见慢性病和罕见病。模型需要结合病例信息给出诊疗方案，内容可包括一般治疗、药物治疗、手术治疗、随访和监测建议。

### 7 病情分析

该子集强调医学量表和公式计算。样例要求模型结合常见医学评分、量表或计算公式综合评估患者当前状态，适合用于测试医学计算、指标解释、风险分层和结果解读能力。

### 8 鉴别诊断

该子集覆盖基层常见病和慢性病，要求模型结合患者信息和基础检查进行鉴别诊断，并给出相应依据。样例适合用于训练模型构建候选诊断、比较关键鉴别点、说明支持与排除依据。

### 9 诊疗处置建议

该子集面向进一步诊疗决策，要求模型根据患者信息、基础检查和疾病特点，提出进一步检验检查、药物治疗、手术治疗、转诊或随访等处置建议，适合医疗问答和临床路径辅助场景。

### 10 病历文本结构化

该子集面向病历文本结构化抽取，内容包含病人基本信息、症状描述及检验检查结果。任务关注体温、脉搏、心率、血压、呼吸频率、腹部体征等结构化字段，适合信息抽取、病历解析和结构化建模。

## 字段说明

不同子集沿用原始题表字段，常见字段包括：

| 字段 | 含义 |
| --- | --- |
| 数据集序号/数据库 | 开源子集编号，已统一为 1-10。 |
| 题量序号/题号 | 当前子集内的样例编号，已统一重排为 1-100。 |
| 内容/数据/题目/题型 | 题干、病例、问题和作答要求。 |
| 来源/来源说明 | 数据来源、文献来源或加工说明。 |
| 分类/类别 | 医学方向、疾病类别、场景类别或任务分类。 |

## 使用建议

- 医学问答与临床推理：可直接读取 Excel 中的题干、病例和答案要求字段，构造问答或指令微调样本。
- 任务分类评测：可按子集编号或分类字段拆分评测集，观察模型在不同医学任务上的表现差异。
- 数据格式参考：可结合 `metadata/manifest.json` 查看每个子集的文件路径、样本数量和任务说明。

## 合规说明

本开源版本为样例数据集，仅保留每个子集 100 条样例。数据经过整理、抽样和必要的格式规范化处理，用于科研、教学、模型评测和产品验证参考，不应作为临床诊疗依据。使用者应遵守医疗数据、个人信息保护和模型安全相关法律法规。
